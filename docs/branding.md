# Siesta Branding

## Project

**Siesta**

Siesta is an e-commerce storefront MVP intended to demonstrate a realistic small-to-medium online store experience.

## Brand Direction

The current visual direction is:

- warm
- minimal
- approachable
- product-focused
- modern
- understated

The design should feel more like a polished independent storefront than a generic enterprise dashboard.

## Tone

The interface should communicate:

- simplicity
- clarity
- calmness
- trust
- product quality

Avoid overly corporate language and excessive visual decoration.

## Current Content

Public brand-facing areas include:

- Home
- Products
- About
- FAQ
- Contact
- Cart
- Checkout

## Logo / Assets

The repository should be treated as the source of truth for currently approved logo and image assets.

Do not invent replacement branding during routine feature development.

## Future Branding Work

Branding can be refined during the portfolio/client-review stage.

Potential future work:

- final logo
- finalized brand palette
- photography direction
- typography selection
- marketing copy
- social media identity

These are presentation decisions rather than core application architecture.
